# Project File Structure

## Core Application
- **app.py**: Primary Streamlit frontend. Handles state persistence and UI layout.
- **backend.py**: FastAPI backend. Manages document parsing (PDF/TXT), storage, and retrieval logic.
- **requirements.txt**: Project dependencies.

## Static Dashboard (Visualization)
- **index.html**: Static dashboard structure.
- **styles.css**: Cyberpunk styling for the dashboard.
- **dashboard.js**: Dashboard UI logic.
- **graph.js**: Interactive graph visualization engine.
- **server.py**: Static file server (Port 8080).

## Documentation
- **README.md**: Overview and quick start.
- **SETUP.md**: Installation instructions.
- **00-START-HERE.md**: Final summary and launch guide.
- **FILES.md**: This file.

## Scripts
- **run.bat**: Main launcher script.
- **start-server.bat**: Static server launcher.
