# ✅ GraphRAG Multi-Document Intelligence Assistant

## 🎯 System Ready

The GraphRAG Assistant is now configured with real document parsing and state persistence.

### 🚀 Quick Start
1. **Backend**: `python backend.py` (Port 8000)
2. **Frontend**: `streamlit run app.py` (Port 8501)

### 📄 Document Analysis
Upload PDFs or TXT files via the Streamlit interface. The system now:
- **Parses** real text from your documents.
- **Persists** state across Streamlit reruns.
- **Retrieves** context dynamically based on your queries.
- **Fails** clearly if no documents are uploaded.

### 📊 Visualization
The static dashboard is available on **Port 8080** (via `python server.py`) for viewing the graph structure.
