## 🛠️ Customization (Easy!)

### Change Colors
Edit `config.js`:
```javascript
theme: {
    accentCyan: '#00d4ff',      // Main color
    accentOrange: '#ffb800',    // Supplier color
    accentGreen: '#00ff88',     // Alternative color
}
```

### Change Port
```bash
python server.py 3000  # Use port 3000 instead
```

### Add Your Supply Chain Data
Edit `config.js` demo section:
```javascript
nodes: [
    { id: 'supplier1', label: 'My Supplier', type: 'supplier', status: 'stable' },
    { id: 'facility1', label: 'My Facility', type: 'facility', status: 'stable' },
]
```

### Enable Debug Mode
Edit `config.js`:
```javascript
debug: { enabled: true }  // Shows console logs
```
